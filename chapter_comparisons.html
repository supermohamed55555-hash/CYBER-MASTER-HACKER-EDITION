1. Sniffing vs. Spoofing vs. Spamming CIA TRIAD IMPACT

المقارنة دي مهمة جداً ومحورية في فهم التأثير المباشر لكل هجوم على أركان الـ **CIA Triad** (السرية، السلامة، والتوافر)، بجانب الميكانيزم الأساسي لكل منها:
Attack Type Definition & Mechanism (كيف يعمل؟) CIA Triad Element Impacted (العنصر المتضرر) Impact Severity & Goal (الهدف الرئيسي)
Sniffing (التنصت) Capturing and monitoring data packets flowing across a network using software/hardware (sniffers) without altering the content. (سلبى) Confidentiality (السرية) Breaches confidentiality because sensitive data (credentials, messages) is exposed to unauthorized listeners.
Spoofing (تزييف الهوية) Falsifying data (IP addresses, MAC, DNS, or Email headers) to impersonate a trusted entity or device. (إيجابى) Integrity (السلامة) & Authenticity Compromises system integrity and trust by executing unauthorized redirection, bypassing firewalls, or sending modified packets.
Spamming (الرسائل المزعجة) Sending unsolicited bulk messages (advertisements, scams, or malware installers) to a massive number of users. Availability (التوافر) Wastes resources, clogs inboxes, and exhausts server bandwidth and storage, leading to resource depletion (DoS).

2. Active Attacks vs. Passive Attacks DETECTION vs PREVENTION

المقارنة الكلاسيكية لنوعي الهجمات من حيث إمكانية منعها، اكتشافها، وتأثيرها:
Feature Passive Attacks (الهجمات السلبية) Active Attacks (الهجمات الإيجابية)
Primary Goal Read/monitor transmissions (steal information). Modify data stream, inject false data, or block services.
System Alteration No data is modified or deleted. Data is modified, replayed, or interrupted.
Examples Eavesdropping, traffic analysis, packet sniffing. Denial of Service (DoS), Masquerade, Replay, Modification.
Focus of Defense Prevention (سهل المنع باستخدام التشفير ولكن صعب جداً اكتشافه لأنه لا يترك أثراً). Detection & Recovery (صعب جداً منعه بشكل استباقي ولكن سهل اكتشاف حدوثه بسبب الأثر التخريبي).
CIA Triad Impact Compromises Confidentiality. Compromises Integrity & Availability.

3. Malware Type Classifications THREAT MATRIX

Malware Type Needs Host File? (ملف حاضن) Self-Replicating? (انتشار ذاتي) Primary Goal / Damage
Virus Yes (attached to .exe) Yes (within system) Modifies/deletes files, causes software crashes.
Worm No (Standalone) Yes (Across network automatically) Consumes network bandwidth and memory, causing network collapse.
Trojan No (Masquerades as safe) No Creates Backdoors for remote control, steals credentials.
Spyware No No Secretly monitors keystrokes and logs browsing data.
Ransomware No No (unless worm-hybrid) Encrypts user data and locks screen, demanding financial ransom.

4. Symmetric vs. Asymmetric Encryption CRYPTOGRAPHY

Feature Symmetric (التماثلي) Asymmetric (اللاتماثلي)
Number of Keys 1 shared key (used for encryption & decryption). 2 keys (Public Key for encryption, Private Key for decryption).
Speed Very Fast (efficient for massive data transmission). Slow (requires heavy modular arithmetic calculations).
Key Exchange Difficult (how to send the secret key safely to the other side?). Easy (public keys are made public to everyone).
Popular Algorithms DES, 3DES, AES, RC4, One-Time Pad (OTP). RSA, Diffie-Hellman, ECC (Elliptic Curve).
